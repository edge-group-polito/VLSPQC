# Official Falcon round-3 KAT files

Verbatim copies of `KAT/falcon512-KAT.rsp` and `KAT/falcon1024-KAT.rsp` from the Falcon round-3 submission package
(<https://falcon-sign.info/falcon-round3.zip>, package SHA-256 `d625407dbda9e5835f610aaeba1147e029988a6610e0107dfd292033138e1d47`, downloaded 2026-10-20).
100 records each, generated by the package's `PQCgenKAT_sign.c`. Falcon is MIT-licensed (the Falcon Project); these are test data.

| File | SHA-256 |
|---|---|
| `falcon512-KAT.rsp` | `dd75c946fdedef4ec46a2bee7e10c65c9126f1a839b9ced6921fd45f7354b5cd` |
| `falcon1024-KAT.rsp` | `036a0bf5260573cec44977284dfef756cd1143db9961b981bd1fb55828acb20d` |

They are replayed by `make test-falcon-512-official` and `make test-falcon-1024-official` (both part of `make test-falcon` and therefore of `make test-all`)
with `harness/gen/main_falcon_official.c`: each record's `seed` initializes the NIST DRBG, which supplies the key-generation seed, the nonce and the signing seed
exactly as the original generator drew them; `pk`, `sk`, `smlen` and `sm` are compared byte for byte and the signature is verified.
The `.rsp` extension is normally git-ignored; `.gitignore` has an exception for this directory.
